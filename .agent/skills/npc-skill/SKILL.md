# NPC 与生态系统 (NPC & Beastiary)

## 1. 动态关系网系统
> *江湖之中，恩怨情仇如蛛丝般交织。一言一行，皆可牵动人心向背。*

### 1.1 好感度机制
每个NPC维护一个 `-100 ~ +100` 的好感度数值，决定其对主角的态度：
- **死敌** (-100 ~ -75)：不共戴天，见面即战
- **仇视** (-74 ~ -50)：拒绝合作，可能设伏
- **冷淡** (-49 ~ -25)：对话生硬，不愿透露信息
- **陌生** (-24 ~ 24)：萍水相逢，中立态度
- **友善** (25 ~ 49)：愿意提供帮助与线索
- **信任** (50 ~ 74)：可招募入队，共享秘密
- **挚友** (75 ~ 100)：生死之交，解锁专属剧情与传承

### 1.2 人格偏好联动
NPC对主角的四维人格（正/邪/狂/狷）有不同偏好，影响好感度增减速率：
- 正派NPC（如段思平）对「正」值高者更易产生好感
- 邪道NPC（如何紫菀）对「邪」值高者态度更友善
- 隐士NPC（如扫地僧）偏好「狷」值高的内敛之人

## 2. 队友互动系统

### 2.1 招募机制
- **基础条件**：好感度达到「信任」(≥50)
- **专属条件**：部分队友需完成特定任务或满足人格阈值
- **队伍上限**：最多同时携带4名队友

### 2.2 羁绊效果
队友间存在特殊羁绊关系，触发联动增益：
- **【双剑合璧】**：李叹 + 漆笑儿同队，攻击+15%
- **【心有灵犀】**：颜玉书好感度达90，解锁隐藏结局线
- **【回春妙手】**：程雁华好感度达60，战后自动恢复气血

### 2.3 阵营冲突
正邪阵营队友同时在队时，可能触发内部矛盾剧情，需玩家调解。

### 2.4 好感度变化公式 (Goodwill Calculation)
玩家行为触发好感度变化时，必须即时更新 `npc_list.md`，数值参考如下：
- **任务完成**：+10 ~ +25（视任务重要性）
- **赠送契合礼物**：+5 ~ +15
- **战斗中保护**：+10 ~ +20
- **符合价值观对话**：+3 ~ +8
- **伤害利益**：-15 ~ -30
- **违背承诺**：-20 ~ -40
- **战斗中抛弃**：-25 ~ -50

## 4. 兽王图鉴 (Beast Kings)
野外分布着强力的兽王，可击杀或通过【兽王册】捕捉。
- **白熊王**: 极北雪域，附带冻结。
- **雪豹王**: 西北雪山，高闪避。
- **白鳄鱼**: 死亡沼泽，需【纪玫湘任务】触发。
- **猿王 (猴三)**: 东部海岛，通过解谜开启。

## 5. 互动逻辑
- **招募**: 需完成特定主线或满足善恶值要求。
- **捕捉**: 使用 `use beast_manual` 指令，目标 HP < 20% 时成功率上升。
- **阵营**: 善恶值（正/邪）直接影响 NPC 的初始态度和交互分支。

## 6. 女性 NPC 状态记录 (Female NPC Status Recording)
> **直白描述准则 (Straightforward Description Guidelines)**
本系统使用直白、现代的词汇记录女性 NPC 的体态特征与状态变化。

### 6.1 词汇规范 (Vocabulary Standard)
使用直白的中文解剖学词汇，禁止过度文学化。

| 部位类型 | 可用词汇 |
|---------|---------|
| 面部/表情 | 面颊泛红、脸红、耳根发烫、眼眶微红、嘴唇颤抖等 |
| 胸部/乳房 | 乳房、胸部、乳头（颜色、硬度、敏感度） |
| 私密部位 | 阴唇、阴蒂、阴道、臀部、肛门 |
| 体温/体感 | 体温升高、身体发烫、心跳加速、呼吸急促 |
| 体态/动作 | 身体紧绷、肌肉颤抖、四肢酸软、站立不稳 |
| 体香/气味 | 体香、体温气味（随情绪变化） |

### 6.2 状态变化规则 (State Change Rules)

**核心原则**：状态必须跟随情节发展实时更新。

1. **情绪触发**：不同情绪会导致不同生理反应
   - 害羞 → 面颊泛红、耳根发烫、心跳加速、阴道湿润
   - 紧张 → 呼吸急促、乳房敏感度上升、身体僵硬
   - 愉悦 → 面色红润、体温微升、眼神柔和
   - 恐惧 → 面色苍白、身体颤抖、乳房收缩

2. **情节关联**：亲密场景、战斗场景、情感升温等不同情节，状态描写重点不同
   - 亲密场景：重点描写敏感部位反应、湿润度、肌肉紧张度
   - 战斗场景：重点描写呼吸、体力消耗、受伤状态
   - 情感场景：重点描写面部表情、眼神变化、心跳

3. **动态更新**：每次交互后，必须更新状态字段
